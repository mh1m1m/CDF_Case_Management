# Target Domain Model

> SYNTHETIC-DATA REFERENCE IMPLEMENTATION. Policy values are configurable and marked `SOURCE_REQUIRED` or `OWNER_DEFAULT`.

## 1. Aggregate map

```
Case (case_mgmt.case_record, source_type)
 ├── CaseSubject*  (person, category, sector)
 ├── Allegation*   (subject?, policy/law reference)
 │    └── Finding* (per allegation × subject)
 ├── EvidenceLink* (evidence → allegation | finding)
 └── Proceeding*   (type, parent?, status, waiting_reason, suspension_reason, outcome_code)
      ├── PRELIMINARY_REVIEW → PreliminaryRecommendation (preparer, reviewer, approver)
      ├── COMMITTEE_INVESTIGATION → CommitteeProceeding (member + rule snapshots)
      │      ├── Meeting* → Agenda, Invitee, EligibilitySnapshot, ConflictDeclaration, Attendance
      │      ├── VoteItem* → Vote*, CastingVote?
      │      ├── Minutes* → MinutesReview*
      │      └── RecommendationPackage* → Item* (scope: subjects / allegations / case)
      ├── LEGAL_REVIEW → LegalReviewRequest → PacketItem*, Opinion
      ├── AUTHORITY_DECISION → AuthorityDecision (source document required to be effective)
      ├── CORRECTIVE_ACTION → CorrectiveAction*
      └── GRIEVANCE → Grievance (LINKED | STANDALONE) → Admissibility, Outcome*, Reinvestigation route

Referral (intake.referral) ──ACCEPT──▶ Case(source_type = DIRECT_REFERRAL)
Committee (committee.committee) → Formation → Seat → Membership (effective-dated) ; RuleSet (effective-dated) ; Delegation
Sector (iam.sector) → SectorMembership (HEAD) ; SectorDelegation (REFERRAL_APPROVAL)
Notification (notify.*), Export (exchange.export_*), BCP import (exchange.bcp_*)
```

## 3. Value objects and vocabularies

- `source_type`: WHISTLEBLOWING, DIRECT_REFERRAL, DIRECT_GRIEVANCE, OTHER_AUTHORIZED_SOURCE.
- `proceeding_type`: PRELIMINARY_REVIEW, INVESTIGATION, COMMITTEE_INVESTIGATION, LEGAL_REVIEW, AUTHORITY_DECISION, CORRECTIVE_ACTION, GRIEVANCE, REINVESTIGATION.
- `seat`: CHAIR, DEPUTY_CHAIR, SECRETARY, ALTERNATE_SECRETARY, MEMBER, ALTERNATE_MEMBER.
- `vote_choice`: APPROVE, REJECT, ABSTAIN, RECUSED, ABSENT, UNABLE_TO_VOTE.
- `quorum_type`: MAJORITY_ELIGIBLE, FIXED_NUMBER, PERCENTAGE, CUSTOM.
- `recommendation_item_type`: FINDING, DISCIPLINARY_SANCTION, CORRECTIVE_ACTION, GOVERNANCE_REMEDIATION, EXTERNAL_REFERRAL, NO_VIOLATION, CLOSE_WITHOUT_SANCTION, LEGAL_ACTION, OTHER.
- `authority_outcome`: APPROVE_AS_RECOMMENDED, MODIFY, REJECT, RETURN_TO_COMMITTEE, APPROVE_PARTIALLY, OTHER.
- `grievance_channel`: EMPLOYEE_PORTAL, EMAIL, PHYSICAL, SECRETARY_ENTRY, BCP_IMPORT, OTHER.
- `provenance`: ORIGINAL_EVENT_AT, RECORDED_OFFLINE_BY, IMPORTED_AT, IMPORTED_BY, SOURCE_WORKBOOK_ID, flags RECORDED_OFFLINE / IMPORTED_LATER.

TS mirrors live in `packages/domain` and are checked by `tests/security/mirrors.spec.ts`.

## 4. Roles

New roles (reference data, migration): `COMPLIANCE_SECTION_MANAGER`, `GRC_SECTOR_HEAD`, `SECTOR_HEAD`, `EMPLOYEE` (self-service subject surface). Existing `COMMITTEE_CHAIR` / `COMMITTEE_MEMBER` / `COMMITTEE_SECRETARY` become capability prerequisites: they never grant case access on their own; an effective membership in the proceeding's committee does.
