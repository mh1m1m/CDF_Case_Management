# UAT Synthetic Data

Everything here is invented for testing (CLAUDE.md §1). No real names, reports, cases, organisations' internal details, identity numbers or documents. Names follow the Greek-letter pattern; emails end in `@example.test`; case numbers carry the `CDF-DEMO` marker. Testers must not type anything real into DEMO, even "just to see". Anything that looks real in a UAT record is a defect in the record and is deleted.

### Execution order

Some scenarios change shared seed state. Run Wave 1 in this order so earlier scenarios do not invalidate later ones:

1. UAT-ENV-01..04
2. UAT-PORTAL-01..05, UAT-VAULT-01, UAT-INTAKE-01..02
3. UAT-WF-01..03, UAT-COI-02
4. UAT-AUTHZ-01..02 (lead must still have access to 0001)
5. UAT-EVID-01..04
6. UAT-VAULT-02, UAT-ADMIN-01..03
7. UAT-COI-01 (removes lead's access to 0001; run last)
8. UAT-UX-01..02 (may reuse any state)

Between cycles DEMO is re-seeded only by a human decision (CLAUDE.md §11, "production-like environment resets"); otherwise the next cycle starts from the state the last one left and the test lead notes it.

## 5. Evidence files

Generate the files locally; do not download test files from the internet except the EICAR string, which testers type from eicar.org or copy from `tests/e2e/evidence.spec.ts`.

```bash
printf '%%PDF-1.4\n%% SYNTHETIC UAT EVIDENCE EV-PDF-1 - CDF reference implementation - no real data\n1 0 obj<</Type/Catalog/Pages 2 0 R>>endobj\n2 0 obj<</Type/Pages/Count 0/Kids[]>>endobj\ntrailer<</Root 1 0 R>>\n%%%%EOF\n' > EV-PDF-1.pdf
printf '%%PDF-1.4\n%% SYNTHETIC UAT EVIDENCE EV-PDF-2 - CDF reference implementation - no real data\n1 0 obj<</Type/Catalog/Pages 2 0 R>>endobj\n2 0 obj<</Type/Pages/Count 0/Kids[]>>endobj\ntrailer<</Root 1 0 R>>\n%%%%EOF\n' > EV-PDF-2.pdf
printf 'SYNTHETIC UAT: plain text pretending to be a PDF\n' > EV-FAKE-PDF.pdf
head -c 27262976 /dev/zero | tr '\0' 'A' > EV-BIG.txt   # 26 MiB, over the 25 MiB limit
sha256sum EV-PDF-1.pdf EV-PDF-2.pdf
```

| Id          | File            | Expected outcome                              | SHA-256 (for comparison)                                           |
| ----------- | --------------- | --------------------------------------------- | ------------------------------------------------------------------ |
| EV-PDF-1    | EV-PDF-1.pdf    | Accepted, Clean, Available                    | `603baba196cbac9e31e87a537371fd2fd7299866c1d44417aca1659b1ea61c6e` |
| EV-PDF-2    | EV-PDF-2.pdf    | Accepted as version 2; refused when repeated  | `8cbf04397b21c97669a79d2e4a82fa87bcb5f3d2236b905d411ee1997ec064b4` |
