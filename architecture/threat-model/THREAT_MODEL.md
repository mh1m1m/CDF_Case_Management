# Threat Model

Protocol §63. Method: STRIDE over the two trust boundaries (internet → whistleblowing-web; authenticated employee → investigation-web) and the database boundary. Every critical threat maps to a control, its implementation, and a test. Rows whose phase has not started say so.

## Assets

Reporter identity (highest) · case content and allegations · evidence objects · audit ledger · role assignments · report secrets.

## Trust boundaries

1. Internet ↔ whistleblowing-web (untrusted, anonymous)
2. Employee browser ↔ investigation-web (authenticated)
3. Next.js server ↔ PostgreSQL (security context per transaction)
4. Next.js server ↔ object storage (service credential, server only)
